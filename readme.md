# Disease Prediction Using Clinical Data

## Overview

This project uses machine learning to predict diabetes outcomes from clinical measurements.

The dataset contains patient-level variables including glucose, blood pressure, BMI, insulin, age, pregnancies and diabetes pedigree function.

## Objectives

The main objectives were to:

* clean and preprocess clinical data
* explore relationships between clinical variables
* build a baseline Logistic Regression model
* build a Random Forest classifier
* compare model performance using classification metrics
* examine feature importance
* generate predictions for new patient data

## Methods

The workflow was:

Clinical Data
→ Data Cleaning
→ Exploratory Data Analysis
→ Train/Test Split
→ Logistic Regression
→ Random Forest
→ Model Evaluation
→ Feature Importance
→ Prediction

## Models

### Logistic Regression

Used as an interpretable baseline for binary classification.

### Random Forest

Used as a non-linear tree-based model that can capture more complex relationships between clinical variables.

## Evaluation

The models were evaluated using:

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC
* Confusion Matrix
* ROC Curve

## Key Learning

This project demonstrates machine-learning workflow for clinical prediction, including handling missing clinical measurements, model comparison and evaluation.

## Dataset

The dataset used in this project was obtained from the Pima Indians Diabetes dataset, available in Jason Brownlee's public GitHub repository.
